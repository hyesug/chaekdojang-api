# 유료 운세 AI 개인정보·결제 사전 감사

> 기준 브랜치: `staging` / 점검일: 2026-10-01
>
> 이 문서는 코드 사실과 공식 자료를 대조한 기술 감사다. 법률 자문이나 확정된
> 개인정보처리방침·이용약관·환불정책이 아니다.

## 개인정보 흐름

```text
OAuth 제공자 → users / user_auth_providers → 로그인 쿠키
운세 입력 → 브라우저 계산 → [저장 선택 시] fortune_profiles
                         └→ [AI 질문 시] Next /fortune-ai → Anthropic 또는 OpenAI
AI 이용 결과 → ai_credit_reservations / ai_usage_records / ai_credit_ledger
질문권 결제 → ai_credit_orders → PortOne 결제 조회 → 질문권 원장
HTTP 요청·이벤트 → access_logs / metric_events → 관리자 화면
```

## 확인된 정책·코드 불일치

1. 개인정보처리방침은 AI 이전받는 자를 Anthropic만 표시하지만, 실제 `/fortune-ai`는
   `GPT_SOL`, `GPT_ASTRA`에서 OpenAI API에도 같은 문맥과 질문을 전송한다.
2. 개인정보처리방침은 AI 질문과 답변을 서버에 저장하지 않는다고 하나, 원문은 저장하지
   않아도 `ai_usage_records`가 요청 ID·사용자 ID·모델·사용 시각·토큰·오류 종류를 저장한다.
   이 이용기록의 목적과 보유기간이 정책에 없다.
3. `ai_credit_orders`와 질문권 원장은 유료 거래 정보인데, 보관 근거·기간·탈퇴 뒤의
   분리 보관/접근 차단 규칙이 코드와 정책 모두에 없다.
4. 구매 화면은 상품·수량·가격·만료일은 표시하지만, 환불 핵심 조건, 판매자 정보,
   결제 전 약관/환불정책 확인 및 결제 완료 후 거래내역 제공이 없다.
5. 정책은 네이버가 이름·이메일·프로필 이미지를 제공할 수 있다고 넓게 적지만,
   현재 `OAuthUserInfo`는 네이버에서 ID만 사용한다.
6. 계정 탈퇴는 기존 `Subscription`만 비활성화한다. 새 AI 주문·질문권·이용기록은
   `User` FK를 계속 보유하며 익명화/분리 보관 설계가 없다.
7. 운세 저장 카드에는 보관 사실과 삭제 링크는 있으나, AI 전송 전에 별도의 범위 안내가
   없다. 궁합 상대방 정보는 DB에 저장하지 않지만 AI에 전송될 수 있다.
8. 관리자 화면은 일반 관리자에게 사용자 이메일, 접속 로그, 이벤트 데이터를 폭넓게
   표시한다. 열람·조회 감사로그와 최소권한 분리가 없다.

## 출시 전 차단 항목

- **법률 검토 필요:** 질문권이 디지털콘텐츠에 해당하는지, 사용 개시 전 청약철회 제한의
  표시·동의 방식, 일부 사용 시 환불 계산, 중복 결제·장애 환불 절차.
- **법률·세무 검토 필요:** 거래기록의 정확한 보존 근거·기간, 사업자/통신판매업 신고,
  전자영수증·부가세 처리.
- **개인정보 검토 필요:** Anthropic/OpenAI의 역할(처리위탁·제3자 제공·국외이전)과
  각 제공자의 실제 보관·학습 이용 조건에 맞춘 고지·동의 또는 계약 근거.
- **운영 입력 필요:** 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 사업장 주소,
  고객센터 연락처·이메일, 환불 접수채널, 개인정보 보호책임자/담당부서, PG 계약 정보.

## 권고되는 구현 순서

1. 판매·결제 기능을 기본 비활성으로 유지하고, 정책·판매자 변수 확정 전에는 결제창을 열지 않는다.
2. AI 프롬프트에서 이름 등 직접 식별자를 제거하고, 궁합 상대방 정보는 브라우저 계산 후 일회성 전송임을 명시한다.
3. 거래 보존 기간과 근거가 확정되면 AI 주문/원장에 보존 종료일과 분리 보관 상태를 추가하고,
   탈퇴 시 프로필·운세 원문은 삭제, 거래 데이터는 최소 식별자로 분리한다.
4. 환불 규칙 확정 후에만 환불 API·관리자 승인·PortOne 취소 연동을 추가한다.
5. 약관/개인정보처리방침/환불정책의 버전·시행일·변경이력과 필수 동의 기록을 구현한다.
